## 发布原则

- 公开网页只放 `public` 或已脱敏内容。
- 私密、资产、工作、健康等敏感内容默认不发布。
- 每个知识节点需要有稳定 slug、父节点、关联节点和复盘周期。
- 总框架持续更新，避免 Markdown 文件无结构堆积。
