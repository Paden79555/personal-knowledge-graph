A. Query理解层：把自然语言变成可计算语义
A1 文本标准化与切词
核心能力繁简/大小写/空格/特殊符号/型号格式/拼音/错别字归一；广告行业词、品牌词、地域词要有保护词典。
  • 诊断：OOV率、无结果率、切词后品牌型号破坏率、标准化前后召回变化。
  • 常见坑：iPhone 15 Pro Max、Mate60、SKU型号、医疗/教育专有词被错误切开。
A2 实体识别、实体链接与知识库
诊断项品牌、品类、型号、地点、人群、服务、价格、功能、竞品实体识别，并链接到广告/商品/行业知识库。
  • 指标：实体识别准确率、实体链接覆盖率、实体保留率、错误新增实体率。
  • 项目抓手：做“改写前后实体差分表”，专门抓品牌/型号丢失与幻觉新增。
A3 Slot/属性抽取
实现抓手抽取品类、品牌、型号、价格、颜色、规格、场景、地域、时效、人群、服务方式等结构化 slot。
  • 排序价值：属性越明确，CVR 通常越有判断力；属性被抹掉时 CTR 可能升、CVR/RPM 可能降。
  • 检查：核心 slot 不可删，弱 slot 可降权或保留为候选解释字段。
A4 意图识别与商业意图强度
能力拆解购买、比价、维修、招商、招聘、下载、信息查询、本地服务、售后、竞品比较；再判断商业意图强/中/弱。
  • 方法：规则词典、文本分类、多任务模型、LLM解释标注、小模型蒸馏。
  • 关键判断：CTR 高不等于购买意图强，必须结合 CVR、RPM、负反馈和人工相关性。
A5 类目预测与歧义消解
指标体系query-category、query-industry、query-advertiser intent；解决“苹果”“小米”“java”“python培训”等多义问题。
  • 指标：类目准确率、跨类目坏改写率、类目一致 Top1 占比。
  • 工程点：类目置信度低时减少激进改写，保留原 query 竞争。
B. Query改写层：生成候选而不是直接替换
B1 是否需要改写
触发策略低召回、无结果、低相关、长尾口语、拼写错误、商业意图强但候选少时触发；头部强品牌 query 要谨慎触发。
  • 指标：触发率、无需改写误触率、低召回 query 覆盖率、原 query 胜出率。
  • 原则：改写是候选生成，不是强行替换。
B2 改写类型库
分类清单纠错、同义、缩写补全、属性补全、类目泛化、类目细化、品牌保护、地域补全、意图保持、长尾商业表达转写。
  • badcase：实体丢失、属性丢失、意图漂移、类目错配、过泛化、幻觉新增、高CPC诱导。
  • 产出：每种类型都要有正例、反例、触发条件、过滤条件、分桶指标。
B3 候选生成方法
方法谱系规则/词典、query log、co-click、query-session、query-ad graph、双塔向量、T5/BART、LLM 离线生成。
  • 简单路线：规则词典 + log 共现 + 人工审核。
  • 进阶路线：LLM 离线生成候选，小模型/规则在线过滤，缓存上线。
B4 约束过滤与候选 Rerank
护栏设计实体保留、属性保留、类目一致、意图一致、相关性阈值、商业价值阈值、CPC诱导约束、坏改写分类器。
  • 排序前特征：候选来源、生成置信度、实体差分、slot差分、召回量、历史CTR/CVR、人工相关性。
  • 上线要求：必须可解释为什么候选进入 Top1 竞争。
C. 召回层：让候选 Query 找得到足够好广告
C1 多路召回与适用边界
召回地图倒排召回保精确，向量召回补长尾语义，query2query 补表达差异，query-ad graph 补商业关系，行业/广告主召回补供给。
  • 指标：召回量、有效召回率、相关广告占比、长尾覆盖率、候选多样性、latency。
  • 坑：召回变多不一定变好，可能只是噪声变多。
C2 候选质量画像
离线资产为每个候选 query 记录来源、触发原因、置信度、召回广告数、人工相关性、历史点击/转化、行业分布、广告主覆盖。
  • 项目机会：做“候选 query 质量画像表”，支撑改写、CTR/CVR、排序实验共用。
C3 召回与排序的联动
诊断逻辑候选没进 Top1，可能不是排序错，而是召回广告少、广告质量差、相关性低、CPC低或模型分数低。
  • 必看：召回前后 Top1 来源变化、Top1/Top2 分差、候选召回广告质量分布。
D. CTR层：从点击概率到可信 pCTR
D1 样本、标签与负例
基础口径曝光/点击样本、去重、反作弊、负采样、时间切分、训练/验证穿越检查。
  • 检查：position 是否泄漏，负样本是否被未来点击污染，头部 query 是否压制长尾。
D2 特征体系
特征地图用户、广告、query、上下文、行业、统计、交叉、序列、实时反馈、改写来源、召回来源。
  • 重点：query 改写后的候选质量特征要进入 CTR/CVR 或排序层，否则模型不知道候选从何而来。
D3 模型谱系
学习路线LR、GBDT+LR、FM/FFM、Wide&Deep、DeepFM、DCN/DCNv2、xDeepFM、DIN、DIEN、DSIN、SIM/ETA。
  • 学习方式：每代模型只问一个问题：它解决了线性、交叉、序列、兴趣演化还是长序列检索问题？
D4 Bias、校准与分桶可信度
排序相关Position bias、popularity bias、selection bias、Platt、isotonic、分桶校准、ECE、Calibration curve。
  • 重点：公式使用的是 pCTR 数值，AUC 高但校准差仍会导致 Top1 错误。
E. CVR层：从点击后转化到全空间价值估计
E1 转化标签与归因口径
口径清单转化定义、转化窗口、归因规则、去重规则、多转化价值、跨设备归因、退款/无效转化处理。
  • 检查：先画点击到转化延迟 CDF，再决定训练标签截断窗口。
E2 SSB 与延迟反馈
核心问题CVR 只在点击空间观测，排序却在曝光空间决策；延迟转化会把未到期样本错当负例。
  • 方法：ESMM、延迟反馈建模、样本重加权、未成熟样本过滤。
  • 公式：pCTCVR = pCTR × pCVR。
E3 多任务与业务价值
进阶方向ESMM、MMoE、PLE、AUX loss、转化价值预估、广告主 ROI 约束。
  • 排序影响：pCVR 被 (1+10×pCVR) 放大，校准误差会直接改变 Top1。
F. 排序决策层：把分数变成 Top1 Query
F1 当前公式诊断
诊断字段pCTR、CPC^α、pCVR 放大系数、CPC 门控、Top1/Top2 分差、候选来源、相关性、人工标签。
  • 必须诊断：Top1 flip rate、门控边界样本、高CPC低相关占比、长尾商业 query 被压制比例。
F2 参数与门控实验
实验抓手α sweep、CVR 系数 sweep、CPC 门控阈值、门控平滑、相关性硬护栏、Top1 稳定性约束。
  • 输出：离线重放收益表、Top1 变化样本、主指标与护栏分桶。
F3 多目标排序
目标函数RPM、CTR、CVR、广告主 ROI、相关性、用户体验、预算消耗、长期价值之间的权衡。
  • 进阶：Learning to Rank、约束优化、分场景权重、策略分层、反事实评估。
G. 实验监控层：证明改动是真的好
实验系统AA、AB、CUPED、分桶实验、显著性、护栏指标、badcase 回流、报警面板。
  • 必须分桶：头/腰/尾 query、改写来源、行业、pCTR桶、pCVR桶、CPC桶、门控状态。
  • 主指标：CVR/RPM/CTCVR；护栏：CTR、相关性、负反馈、latency、fallback rate。
H. 工程上线层：让知识变成可运行系统
工程闭环离线样本、在线特征、缓存、蒸馏、fallback、灰度、回滚、日志 schema、dashboard、实验配置。
  • 工程目标：任何 Top1 变化都能在日志里复现为“候选、分数、门控、来源、实验桶”的变化。
  • 上线门禁：可回滚、可监控、可解释、可分桶、可复盘。

Query理解/改写：分类、方法、实现、进阶

Query 改写的核心不是“换词”，而是“候选生成 + 语义约束 + 召回验证 + 排序验证 + 回流学习”。下面每类 badcase 都要能映射到可执行策略。

QR-01
拼写/输入错误
错别字、拼音、英文缩写、型号格式、输入法混淆。
分类
字形错误、音近错误、键盘近邻、型号空格、品牌别名、新词未收录。
简单做法
编辑距离、拼音相似、热门query词典、品牌/型号白名单。
进阶做法
Noisy Channel、seq2seq纠错、BERT纠错、LLM候选生成 + 实体保护过滤。
效果提升
只在低召回/无结果/低置信query触发；保留原query作为候选；按行业维护白名单。
指标
纠错准确率、无结果率下降、坏纠错率、纠错后CTR/CVR/RPM。
QR-02
实体丢失
品牌、型号、地点、人群等核心实体被改没。
例子
“华为mate60手机壳”→“手机壳”；“耐克飞马40”→“跑鞋”。
实现
NER抽取核心实体，建立不可删除规则；实体差分检查；实体链接到品牌/型号库。
进阶
entity-aware rewriting、知识图谱约束、constrained decoding、实体保留reward。
指标
实体保留率、品牌型号保留率、类目一致率、改写后CVR/RPM。
QR-03
属性丢失
颜色、价格、尺寸、功能、场景约束被抹掉。
实现
slot抽取为{品类,品牌,型号,属性,场景,价格,意图}；核心slot不可删，弱slot可降权。
判断
CTR可能上升但CVR下降，说明变泛后更吸睛但购买约束变弱。
QR-04
意图漂移
购买/维修/信息/招聘/招商/下载等意图被误改。
实现
意图分类器 + LLM解释 + 人工标注少量高价值样本；改写前后意图必须一致或可解释。
指标
意图一致率、类目准确率、CVR变化、负反馈、人工相关性。
QR-05~12
其他高频Bad Case
类目错配、过度泛化、幻觉、欠改写、过度改写、长尾口语、高点击低转化、高CPC诱导。
类目错配query-category分类 + co-click类目约束 + 上下文消歧，防止“苹果”手机/水果混淆。
过度泛化term importance、核心词不可删、召回量上升但CVR/相关性下降时回滚。
过度具体化/幻觉禁止新增品牌/型号；LLM输出做实体差分；新增实体必须有证据。
欠改写低召回/无结果/低置信触发；训练“是否需要改写”模型。
过度改写原query保留候选；改写置信度校准；bad rewrite classifier；fallback。
长尾口语LLM离线生成长尾表达、query2query graph、dense retrieval、蒸馏上线。
高点击低转化CTR升但CVR/RPM降时，加入CVR护栏和购买意图一致性约束。
高CPC诱导高CPC低相关Top1占比监控；相关性门控、CPC截断/平滑、多目标约束。
从简到难路线：规则词典 → query log统计共现 → query-ad graph → 向量召回/双塔 → T5/BART生成式改写 → LLM离线生成 + 约束过滤 + rerank + 小模型蒸馏 + 缓存上线。

召回与候选：改写后的Query必须召回得好

倒排召回

适合精确词、品牌型号、强约束query。重点看分词、同义词、term权重和无结果率。

向量召回

适合长尾语义、口语表达、同义意图。重点防止语义近但商业意图错。

图召回

query-ad、query-query、user-query图能补商业关联。重点看噪声边、时间衰减和行业隔离。

候选打标每个候选query必须记录来源、触发原因、置信度、实体保留率、类目一致性、召回量、召回广告相关性。
多路融合不要只合并召回结果，要按query类型、意图、长尾程度、历史表现动态调权。
诊断指标召回量、有效召回率、人工相关广告占比、长尾覆盖率、召回latency、候选多样性。

CTR/CVR：你要学的是可信分数体系

CTR技术树

样本曝光、点击、负样本采样、时间切分、去重、反作弊。
特征用户、广告、query、上下文、统计、交叉、序列、实时特征。
模型LR/GBDT+LR/FM/DeepFM/DCN/DIN/DIEN/SIM，先理解每代解决什么问题。
Biasposition bias、popularity bias、selection bias；需要分桶和反事实思想。
校准Platt、isotonic、分桶校准、ECE；排序公式里校准比单纯AUC更关键。

CVR技术树

标签口径转化定义、窗口、归因、去重、多转化处理。
SSB点击空间训练，曝光空间预测；ESMM用CTR和CTCVR缓解。
延迟反馈转化滞后导致假负样本；先画点击到转化延迟CDF。
多任务ESMM、MMoE、PLE处理CTR/CVR目标关联与冲突。
排序影响pCVR被(1+10×pCVR)放大，校准误差会直接改变Top1。
重要判断：长尾 query CTR 低不一定没价值，可能购买意图强、CVR/RPM高。要把长尾桶单独拿出来看，不能让头部query均值掩盖它。

排序公式：把技术树压缩成一个可诊断目标函数

CPC门控通过：Score = pCTR × CPCα × (1 + 10 × pCVR)
CPC门控不通过：Score = pCTR × CPCα
按 Score 降序取 Top1 作为最优 query。这个公式是学习入口，不是终点。

pCTR

点击概率。重点看校准、长尾低估、position/popularity bias。

CPC^α

商业价值权重。α越大，高CPC候选越容易上浮。

1+10×pCVR

转化价值放大器。pCVR不准时错误会被放大。

门控/Top1

硬门控和Top1都会放大边界误差和排序抖动。

α sweep测试0、0.25、0.5、0.75、1.0，观察Top1 flip、高CPC低相关、RPM/CVR变化。
CVR系数 sweep测试0、2、5、10、20，观察pCVR校准误差被放大后的Top1变化。
门控阈值重点看阈值附近样本，硬门控是否导致候选突然失去CVR加成。
Top1诊断每次实验必须输出Top1归因表、Top1/Top2分差、Top1来源分布。
